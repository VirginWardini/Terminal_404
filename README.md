# TERMINAL 404

A text-based hacking adventure. You are the investigator.

## Run it
    pip install -r requirements.txt
    python app.py
Then open http://127.0.0.1:5000

## Layout
- app.py            Flask game engine (commands, file system, state)
- game_data.json    Story, files, clues, hints (edit this to make your own case!)
- templates/        HTML5 interface
- static/style.css  Terminal look
- static/terminal.js Command input, history (arrow keys), output
